# UAV Dynamics and Control 

Lecture notes, MATLAB-based resources, homework assignments, and project materials for a senior-level course on UAV dynamics and control at the University of Maryland, Baltimore County (UMBC).

**Instructors:**  
Dr. Ankit Goel, Dr. Juan Augusto Paredes Salazar  
Department of Mechanical Engineering  
University of Maryland, Baltimore County  

---

## Repository Contents

This repository includes course materials covering the modeling, analysis, and control of multicopter systems, including:

- Mathematical foundations for dynamical systems  
- Geometry, kinematics, and rigid-body dynamics  
- Multicopter modeling and linearization  
- Control design for UAV systems  
- Sensor modeling and measurement systems  
- Observability and state estimation  
- Observer design and Kalman filtering  
- MATLAB-based simulation and analysis  

---

## Course Structure

The material is organized into three main components:

### Modules (Lecture Notes)
- Module 1: Mathematical Foundations  
- Module 2: Geometry, Kinematics, and Dynamics  
- Module 3: Linearization and Control  
- Module 4: Sensors and Measurement  
- Module 5: State Estimation  

---

### Homework
The repository includes six homework assignments designed to reinforce theoretical concepts and analytical techniques.

Students are expected to attempt all problems independently before consulting any provided solutions or references.

---

### Projects 
Four programming projects focus on modeling, simulation, and control implementation for UAV systems.

Project topics include:
- Dynamic modeling of multicopter systems  
- Control design and simulation  
- Sensor integration and analysis  
- State estimation and filtering  

These projects emphasize connecting theoretical concepts to practical implementation using MATLAB.
